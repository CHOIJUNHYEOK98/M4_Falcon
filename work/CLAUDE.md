# work — 활성 구현 작업 공간

## 역할

현재 진행 중인 **구현·실험 코드**가 사는 곳이다. 프로젝트의 "단일 진실 원본(single source of truth)" 코드는 여기에 둔다.

## 작업 규칙

- 활성 작업만 둔다. **완료·폐기된 작업 트리는 `archive/`로 이동**하여 무수정 보존한다.
- 외부에서 가져온 수정 불가 기준 코드는 `work/`가 아니라 `reference/`에 둔다.
- 빌드 산출물(`*.o`, `*.d`, `build/`, `obj-*/` 등)은 커밋·검색 대상이 아니다(`.gitignore`/`.rgignore`로 제외).
- 측정·문서·논문이 코드를 인용할 때는 항상 이 `work/`의 현재 버전을 기준으로 한다(archive 아님).
