# docs — 권위 문서·측정 결과·인덱스

## 역할

이 폴더는 프로젝트의 **권위 문서(authoritative document)**와 측정 산출물을 모은다. 모든 `.md` 문서는 원칙적으로 여기에 둔다.

## 보관 규칙

- **역할 분리**: 한 문서가 여러 주제를 섞지 않는다. 각 문서는 "이 주제는 여기가 원본"임을 명확히 하고, 다른 문서와 내용을 복붙하지 않는다(상호 참조로만 연결).
- **단일 권위**: 같은 수치·결론을 두 곳에 두지 않는다. 갱신 시 stale 단락은 삭제·통합한다.
- **기본 문서**:
  - `BENCHMARK.md` — 측정 환경·정책·실측 결과.
  - `OPT.md` — 적용 완료된 최적화 기법 카탈로그와 향상률.
  - `TODO.md` — 활성 작업 목록(작업 관리의 단일 소스).

## 확장 (필요 시에만 생성)

프로젝트가 해당 단계에 도달하면 다음을 추가한다 — 미리 빈 파일을 만들지 않는다:

- `OPT_IDEA.md` (미구현·기각된 최적화 아이디어), `MEMORY.md` (살아있는 약속·함정),
  `ARCHITECTURE.md` (의존 그래프·데이터 흐름), `ISSUE.md` (이슈 트래커),
  `METHODOLOGY.md` (방법론), `ai/NAV.md` (작업유형 → 파일:섹션 라우팅).
